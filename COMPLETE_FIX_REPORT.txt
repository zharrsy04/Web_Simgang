1. PROBLEM STATEMENT
================================================================================

Mentor was getting "403 This action is unauthorized" error when clicking the 
Edit button on the "Data Siswa/Mahasiswa PKL Aktif" page.

URL: /mentor/[id]/edit
Error: "This action is unauthorized"

================================================================================
2. ROOT CAUSE ANALYSIS
================================================================================

The authorization system was checking:
  
  if ($sertifikat->created_id === $user->id)
    return true;
  else
    return false;

BUT the problem: The `created_id` COLUMN DID NOT EXIST in the database!

Database Table: tbl_sertifikat_pkl
Status: MISSING created_id column
Result: Authorization check always failed
Error: 403 Unauthorized

================================================================================
3. SOLUTION IMPLEMENTED
================================================================================

Solution had multiple parts:

PART 1: Add Missing Database Column
─────────────────────────────────────
Created migration: 2026_07_24_162234_add_created_id_to_tbl_sertifikat_pkl_table.php

Migration code:
  Schema::table('tbl_sertifikat_pkl', function (Blueprint $table) {
      if (!Schema::hasColumn('tbl_sertifikat_pkl', 'created_id')) {
          $table->bigInteger('created_id')->nullable()->after('sts_diambil')
                ->comment('ID user (mentor/sekretariat) yang membuat sertifikat');
      }
  });

Status: ✅ Applied successfully

PART 2: Populate Existing Data
──────────────────────────────
Created command: SetCreatedIdForSertifikats

Purpose: Populate NULL created_id values with mentor ID for existing sertifikats
Status: ✅ Executed successfully

PART 3: Query Filter for Mentors
────────────────────────────────
Already fixed earlier in SertifikatController::index()

Code:
  if ($role == 'mentor') {
      $query->where('created_id', Auth::id());
  }

Result: Mentors now only see their own sertifikats
Status: ✅ Already in place

PART 4: Verify Policy Authorization
───────────────────────────────────
Policy in SertifikatPolicy::update()

Code:
  if ($user->role === 'mentor') {
      return $sertifikat->created_id === $user->id;
  }

Status: ✅ Already correct - no changes needed

PART 5: Verify Store Method Sets created_id
──────────────────────────────────────────
In SertifikatController::store()

Code:
  $validatedData['created_id'] = Auth::id();

Status: ✅ Already implemented for new sertifikats
