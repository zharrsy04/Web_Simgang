│ viewed_at        │ TIMESTAMP   │ Waktu mentor lihat              │

POTENTIAL ISSUES & SOLUTIONS
================================================================================

ISSUE 1: Mentor yang sudah memberi nilai kemudian dihapus dari sistem
IMPACT: Nama mentor tidak muncul di tabel nilai siswa
SOLUTION: ✅ Fallback ke username jika nama null
          ✅ Fallback ke '-' jika user sudah dihapus
CODE: {{ $submission->task->assignedByUser->nama ?? 
         $submission->task->assignedByUser->username ?? '-' }}

ISSUE 2: Tugas dihapus tapi submission masih ada
IMPACT: Orphaned submissions di database
SOLUTION: ✅ Cascade delete di migration (future)
          ✅ whereHas check di query (sudah implemented)
PREVENTION: Confirm modal saat hapus tugas yang ada submission

ISSUE 3: Rata-rata nilai jadi 0.00 jika semua tugas belum dinilai
IMPACT: Confusing untuk siswa (angka 0 vs "tidak ada data")
SOLUTION: ✅ Empty state handle di view
          ✅ Check count() > 0 sebelum render tabel

ISSUE 4: Feedback terlalu panjang membuat row sangat tinggi
IMPACT: Tabel sulit dibaca
SOLUTION: ✅ Limit 80 karakter di main row
          ✅ Full feedback di row terpisah dengan collapse
          ✅ Pre-wrap untuk preserve formatting

ISSUE 5: Multiple grades untuk satu task (jika mentor edit berkali-kali)
IMPACT: Data inconsistent
SOLUTION: ✅ Update existing record (bukan insert new)
          ✅ Grade & graded_at di tabel submission (bukan tabel terpisah)
