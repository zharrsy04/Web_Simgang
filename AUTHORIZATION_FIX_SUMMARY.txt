AUTHORIZATION FIX - MENTOR EDIT BUTTON 403 ERROR
================================================================================

ISSUE:
------
Mentors were getting "403 This action is unauthorized" when clicking Edit button 
on the "Data Siswa/Mahasiswa PKL Aktif" page.

ROOT CAUSE:
-----------
The query filter in SertifikatController::index() was COMMENTED OUT.
This caused mentors to see ALL sertifikats in the system, not just their own.
When they tried to edit another mentor's sertifikat, the authorization policy
correctly rejected the action → 403 error.

THE PROBLEM WAS NOT THE POLICY - THE POLICY WAS CORRECT!
The problem was the data visibility layer (query) showing data that shouldn't 
be visible in the first place.

SOLUTION:
---------
Uncommented the mentor filter to apply data ownership restrictions at query level.
This creates proper "defense in depth" - both query filtering AND policy checks.

FILES CHANGED:
--------------
1. app/Http/Controllers/SertifikatController.php
   
   BEFORE (Line ~137):
   // Sekretariat lihat semua, Mentor lihat semua (filter bisa ditambahkan di future)
   // $query->where('created_id', Auth::id()); 
   
   AFTER (Line ~137):
   // Sekretariat lihat semua, Mentor lihat hanya milik mereka
   if ($role == 'mentor') {
       $query->where('created_id', Auth::id());
   }
