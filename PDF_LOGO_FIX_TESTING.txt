🔍 TROUBLESHOOTING (jika logo masih tidak muncul)
═══════════════════════════════════════════════════════════════════════════════

MASALAH 1: File gambar tidak ditemukan
Solusi:
  1. Verifikasi file ada di: d:\laragon-new\www\web-simgang\public\images\
     - logo-dinascilacap.png
     - logo-Diskominfo.png
     - bg-sertif.png
  2. Cek permission folder (harus readable oleh PHP/web server)
  3. Cek case sensitivity nama file (huruf besar/kecil harus sama persis)

─────────────────────────────────────────────────────────────────────────────

MASALAH 2: Path tidak benar
Solusi:
  1. Di template, pastikan menggunakan:
     {{ public_path('images/logo-dinascilacap.png') }}
     BUKAN:
     {{ asset('images/logo-dinascilacap.png') }}
  
  2. public_path() menghasilkan absolute path:
     d:\laragon-new\www\web-simgang\public\images\logo-dinascilacap.png

─────────────────────────────────────────────────────────────────────────────

MASALAH 3: DomPDF tidak bisa akses file
Solusi:
  1. Pastikan konfigurasi di controller:
     'chroot' => public_path(),
  2. Pastikan 'isRemoteEnabled' => false
  3. Restart server PHP jika perlu: php artisan serve --host=127.0.0.1 --port=8000

─────────────────────────────────────────────────────────────────────────────

MASALAH 4: Cache browser
Solusi:
  1. Clear cache browser (Ctrl+Shift+Delete)
  2. Buka PDF dengan Incognito/Private mode
  3. Hard refresh (Ctrl+F5) pada halaman yang bersangkutan
