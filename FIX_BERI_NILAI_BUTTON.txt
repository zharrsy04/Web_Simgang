PERBAIKAN: TOMBOL "BERI NILAI" DI HALAMAN TUGAS SISWA
================================================================================
Tanggal: 11 Agustus 2026
Issue: Tombol untuk memberi nilai tidak terlihat di halaman daftar tugas siswa

================================================================================
MASALAH
================================================================================

User melaporkan:
"mana tombol buat ngasih nilainya? belum ada"

ANALISIS:
- User berada di halaman: /mentor/tasks/tugas-siswa/{siswaId}
- Halaman ini menampilkan DAFTAR tugas untuk satu siswa
- Tombol "Beri Nilai" sudah diimplementasikan di halaman DETAIL tugas
- Tapi tidak ada cara untuk mengakses halaman detail dari daftar tugas
- User perlu klik tugas dulu untuk buka detail, baru bisa beri nilai

SOLUSI:
Tambahkan tombol "Beri Nilai" langsung di card tugas (halaman daftar)
yang akan redirect ke halaman detail tugas.

================================================================================
IMPLEMENTASI
================================================================================

FILE YANG DIUBAH:
resources/views/mentor/tasks/tugas-siswa.blade.php

PERUBAHAN:
Ditambahkan tombol di sebelah tombol Edit dan Hapus:

KONDISI 1: Tugas Belum Dikumpulkan
→ Tombol "Beri Nilai" TIDAK MUNCUL
→ Hanya ada tombol Edit dan Hapus

KONDISI 2: Tugas Sudah Dikumpulkan, Belum Dinilai
→ Tombol "Beri Nilai" MUNCUL (warna biru info)
→ Icon: ⭐ star
→ Text: "Beri Nilai"
→ Action: Redirect ke halaman detail tugas
→ URL: /mentor/tasks/{id}

KONDISI 3: Tugas Sudah Dinilai
→ Tombol berubah jadi "Lihat Nilai" (warna hijau success)
→ Icon: ⭐ star
→ Text: "Nilai: 85" (menampilkan nilai yang sudah diberikan)
→ Action: Redirect ke halaman detail tugas untuk lihat/edit nilai
→ URL: /mentor/tasks/{id}

```php
@if($hasSubmission)
    @php
        $latestSubmission = $task->submissions->first();
```

FLOW PENGGUNAAN
================================================================================

SCENARIO 1: Beri Nilai Untuk Tugas yang Baru Dikumpulkan
1. Mentor buka /mentor/tasks/tugas-siswa/{siswaId}
2. Lihat daftar tugas siswa
3. Tugas yang sudah dikumpulkan ada badge "Ada Pengumpulan"
4. Klik tombol "⭐ Beri Nilai" (warna biru)
5. Redirect ke halaman detail tugas
6. Modal "Beri Nilai" sudah tersedia di halaman detail
7. Isi nilai dan feedback
8. Submit
9. Kembali ke daftar tugas (atau tetap di detail)
10. Tombol berubah jadi "Nilai: 85" (warna hijau)

SCENARIO 2: Lihat/Edit Nilai yang Sudah Diberikan
1. Mentor buka /mentor/tasks/tugas-siswa/{siswaId}
2. Tugas yang sudah dinilai menampilkan tombol "Nilai: 85" (hijau)
3. Klik tombol tersebut
4. Redirect ke halaman detail tugas
5. Badge nilai dan tombol "Edit Nilai" sudah ada
6. Klik "Edit Nilai" untuk mengubah nilai/feedback
7. Submit perubahan
8. Nilai terupdate
