VALIDATION LOGIC - DETAILED FLOW
═══════════════════════════════════════════════════════════════════════════════

TRIGGER: Mentor clicks "Create Task" → Fills form → Submits

STEP 1: Input Validation (Laravel Validation)
  - bidang: required|string|max:100
  - sertifikat_pkl_id: required|integer|exists:tbl_sertifikat_pkl
  - title: required|string|max:255
  - description: nullable|string|max:5000
  - due_date: nullable|date|after:today

STEP 2: Get Sertifikat & User Context
  - $sertifikat = SertifikatPKL::findOrFail($validated['sertifikat_pkl_id'])
  - $mentor = Auth::user()

STEP 3: LEVEL 1 VALIDATION - Mentor-Student Relationship
  if ($sertifikat->created_id !== $mentor->id) {
      return error(403, "Anda tidak menangani siswa ini");
  }

STEP 4: LEVEL 2 VALIDATION - Bidang Placement Check
  - $placement = PenempatanBidang::where('id_sertifikat', $sertifikat->id)->first()
  - $studentBidang = $placement 
      ? $placement->bidang_ditempatkan 
      : $sertifikat->bidang
  if ($studentBidang !== $validated['bidang']) {
      return error(403, "Siswa di bidang {$studentBidang}, bukan {$validated['bidang']}");
  }

STEP 5: LEVEL 3 VALIDATION - Mentor-Bidang Handling
  - $mentorBidang = SertifikatPKL::where('created_id', $mentor->id)
      ->where('bidang', $validated['bidang'])
      ->exists()
  if (!$mentorBidang) {
      return error(403, "Anda tidak menangani bidang ini");
  }

STEP 6: All Validations Passed - Create Task
  DB::beginTransaction();
  $task = Task::create([
      'sertifikat_pkl_id' => $validated['sertifikat_pkl_id'],
      'assigned_by' => $mentor->id,
      'title' => $validated['title'],
      'description' => $validated['description'],
      'due_date' => $validated['due_date'],
      'status' => 'pending',
  ]);
  DB::commit();

STEP 7: Success Response
  Log::info('Task created successfully', [...])
  return redirect()->route('mentor.tasks.index')
      ->with('success', 'Tugas berhasil dibuat!');
