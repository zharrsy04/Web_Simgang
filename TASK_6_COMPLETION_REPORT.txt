📝 NOTES
═══════════════════════════════════════════════════════════════════════════════

WHY THIS FIX WORKS:
DomPDF adalah server-side PDF generator. Ia tidak bisa melakukan HTTP request
untuk mengambil gambar via asset() atau URL. DomPDF butuh direct filesystem 
access dengan absolute path.

Setting 'chroot' => public_path() memberitahu DomPDF bahwa folder base untuk
file access adalah [project_root]/public/, sehingga public_path('images/logo.png')
bisa di-resolve menjadi absolute path yang valid.

ALTERNATIVE SOLUTIONS (not used):
- Base64 encode images: Membuat template bloated
- Copy images to storage/: File duplication
- External image hosting: Butuh internet access (tidak reliable)

CHOSEN SOLUTION:
✓ public_path() + chroot = Optimal, no duplication, secure
