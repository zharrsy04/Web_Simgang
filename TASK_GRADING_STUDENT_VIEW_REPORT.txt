================================================================================
STRUKTUR DATA YANG DITAMPILKAN
================================================================================

DATA DARI QUERY:
$gradedTasks = TaskSubmission dengan kondisi:
- Task terkait dengan sertifikat siswa (sertifikat_pkl_id = $id)
- Status = 'graded'
- Grade tidak null (sudah ada nilai)
- Relasi loaded: task.assignedByUser, student
- Urutan: graded_at DESC (terbaru dulu)

KOLOM YANG DITAMPILKAN:
1. No                     → Loop iteration
2. Judul Tugas            → $submission->task->title
3. Mentor Pemberi Tugas   → $submission->task->assignedByUser->nama
4. Nilai                  → $submission->grade (dengan badge warna)
5. Tanggal Dikumpulkan    → $submission->submitted_at
6. Tanggal Dinilai        → $submission->graded_at

INFORMASI TAMBAHAN:
- Feedback Mentor         → $submission->mentor_feedback (ditampilkan jika ada)
- Rata-rata Nilai         → $gradedTasks->avg('grade')

================================================================================
ERROR HANDLING
================================================================================

ERROR 1: Variable $gradedTasks tidak didefinisikan
PENYEBAB: Controller tidak mengirim variable ke view
SOLUSI: ✅ Sudah diperbaiki di PenilaianController::detailNilai()

ERROR 2: Str::limit() not found
PENYEBAB: Helper Str tidak tersedia di Blade
SOLUSI: ✅ Menggunakan \Illuminate\Support\Str::limit()

ERROR 3: Relasi task.assignedByUser null
PENYEBAB: Mentor yang membuat tugas sudah dihapus
SOLUSI: ✅ Ditambahkan fallback: nama ?? username ?? '-'

ERROR 4: Empty state tidak muncul
PENYEBAB: Kondisi @if salah
SOLUSI: ✅ Menggunakan @if($gradedTasks && $gradedTasks->count() > 0)

ERROR 5: Rata-rata tidak muncul
PENYEBAB: Collection kosong
SOLUSI: ✅ avg() akan return 0 jika kosong, dan akan dicek di @if di atas
