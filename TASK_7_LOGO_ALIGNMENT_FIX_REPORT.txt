PERUBAHAN STYLING LOGO (.logo class):

    width: 110px;
    margin-bottom: 30px;              ← Hanya margin bawah, tidak centered
    transition: transform 0.3s ease;
}

SESUDAH (RAPI & CENTERED):
.logo {
    width: 110px;
    height: auto;                     ← Proporsi otomatis
    margin: 0 auto 30px;              ← Centered horizontal + margin bawah
    display: block;                   ← Block element untuk centering
    transition: transform 0.3s ease;
    object-fit: contain;              ← Menjaga aspect ratio logo
}

PENJELASAN PERUBAHAN:
1. height: auto           - Menjaga proporsi tinggi logo
2. margin: 0 auto 30px    - Center horizontal (auto kiri-kanan) + 30px bawah
3. display: block         - Membuat element block agar margin auto bekerja
4. object-fit: contain    - Logo tidak ter-stretch, menjaga aspect ratio

📝 TECHNICAL NOTES
═══════════════════════════════════════════════════════════════════════════════

CSS CENTERING TECHNIQUE:
────────────────────────────────────────────────────────────────────────────────
Untuk center element secara horizontal, digunakan teknik:
1. display: block        - Element harus block-level
2. margin: 0 auto       - Auto margin kiri & kanan = centered
3. width: [fixed]        - Lebar harus defined (110px)

OBJECT-FIT PROPERTY:
────────────────────────────────────────────────────────────────────────────────
object-fit: contain;
- Menjaga aspect ratio original image
- Tidak ter-stretch atau ter-crop
- Image fit dalam container tanpa distorsi

MARGIN SHORTHAND:
────────────────────────────────────────────────────────────────────────────────
margin: 0 auto 30px;
= margin-top: 0
  margin-right: auto     ← Push dari kanan
  margin-bottom: 30px
  margin-left: auto      ← Push dari kiri
  Hasil: Element centered horizontal
