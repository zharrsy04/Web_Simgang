================================================================================
CARA KERJA FITUR
================================================================================

WORKFLOW PENILAIAN:
1. Mentor membuka detail tugas: /mentor/tasks/{id}
2. Jika siswa sudah mengumpulkan (status 'submitted'):
   → Tombol "Beri Nilai" muncul
3. Klik tombol "Beri Nilai":
   → Modal form terbuka
   → Input nilai (0-100, wajib)
   → Input feedback (opsional, max 2000 karakter)
4. Submit form:
   → AJAX POST ke /mentor/tasks/submission/{submissionId}/grade
   → Validasi server-side
   → Update database (grade, mentor_feedback, status='graded', graded_at)
   → Response JSON success
   → Page reload otomatis
5. Setelah dinilai:
   → Badge nilai ditampilkan (misal: "85/100")
   → Tombol berubah jadi "Edit Nilai"
   → Klik "Edit Nilai" untuk koreksi nilai

VALIDASI:
✅ Nilai wajib diisi (required)
✅ Nilai harus angka antara 0-100 (numeric, min:0, max:100)
✅ Feedback opsional, max 2000 karakter (nullable, string, max:2000)
✅ Client-side validation dengan Bootstrap validation
✅ Server-side validation di controller

TAMPILAN DI SISWA:
Siswa dapat melihat nilai dan feedback di halaman:
- /siswa/tasks (list tugas) → Badge "Selesai Dinilai"
- /siswa/tasks/{id} (detail tugas) → Nilai ditampilkan dengan badge hijau
- Feedback mentor ditampilkan jika ada

================================================================================
KEMUNGKINAN ERROR DAN SOLUSI
================================================================================

ERROR 1: Tombol "Beri Nilai" tidak muncul
PENYEBAB: Submission status bukan 'submitted'
SOLUSI: Pastikan siswa sudah upload file (status 'submitted')

ERROR 2: Modal tidak terbuka
PENYEBAB: Bootstrap JavaScript tidak loaded
SOLUSI: Cek <script> Bootstrap di layouts/app.blade.php

ERROR 3: Form submit error 403
PENYEBAB: CSRF token tidak valid
SOLUSI: Cek meta tag csrf-token di layouts/app.blade.php

ERROR 4: Nilai tidak tersimpan
PENYEBAB: Validasi gagal atau route tidak ditemukan
SOLUSI: Cek console browser untuk error AJAX
         Cek Laravel log: storage/logs/laravel.log

ERROR 5: Badge nilai tidak muncul setelah submit
PENYEBAB: Page tidak reload atau status tidak 'graded'
SOLUSI: Cek setTimeout reload di JavaScript
         Cek database: SELECT status FROM task_submissions WHERE id = X
