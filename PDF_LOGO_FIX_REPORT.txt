2. ROOT CAUSE ANALYSIS
═══════════════════════════════════════════════════════════════════════════════

PENYEBAB:
Library DomPDF (yang digunakan untuk generate PDF di project ini) TIDAK BISA 
mengakses gambar melalui HTTP URL atau path relatif. DomPDF hanya bisa membaca 
gambar melalui:
1. Absolute filesystem path (public_path())
2. Base64 encoded image data

MASALAH DI KODE:
Template Blade SUDAH BENAR menggunakan public_path():
  {{ public_path('images/logo-dinascilacap.png') }}

NAMUN konfigurasi DomPDF di Controller SALAH:
  ❌ 'isRemoteEnabled' => true,     // Mencoba akses via HTTP (GAGAL)
  ❌ TIDAK ADA 'chroot' setting     // DomPDF tidak tahu base path

4. PERUBAHAN YANG DILAKUKAN
═══════════════════════════════════════════════════════════════════════════════

SEBELUM (SALAH):
────────────────
$pdf->setOptions([
    'isRemoteEnabled' => true,        ← SALAH: Coba akses via HTTP
    'isHtml5ParserEnabled' => true
]);

SESUDAH (BENAR):
────────────────
$pdf->setOptions([
    'isRemoteEnabled' => false,       ← Matikan remote access
    'isHtml5ParserEnabled' => true,
    'isPhpEnabled' => true,
    'chroot' => public_path(),        ← Tetapkan base path untuk akses file lokal
]);

PENJELASAN:
- isRemoteEnabled => false:  DomPDF tidak boleh akses gambar via HTTP/URL
- chroot => public_path():   Memberitahu DomPDF di mana folder public/ berada
                             sehingga public_path() di template bisa diakses

8. TECHNICAL NOTES
═══════════════════════════════════════════════════════════════════════════════

WHY THIS FIX WORKS:
DomPDF adalah library server-side PHP yang generate PDF. Saat running di server,
DomPDF TIDAK bisa melakukan HTTP request ke dirinya sendiri untuk mengambil 
gambar via asset() atau url(). 

DomPDF butuh:
1. Direct filesystem access ke file gambar
2. Setting 'chroot' sebagai base directory untuk security

ALTERNATIF LAIN (tidak dipakai):
- Base64 encode gambar di template: Membuat file template jadi besar
- Copy gambar ke storage/: Duplikasi file yang tidak perlu

SOLUSI TERPILIH:
✓ public_path() di template + chroot setting di controller
  = Optimal performance, no duplication, secure
